# web_docker_viver
Создать, управлять и удалить контейнеры на одной странице

# Install
```
python -m venv .venv
source .venv/bin/activate
pip install fastapi uvicorn docker websockets python-multipart
```

# Run

```
sudo .venv/bin/python app2.py
```
